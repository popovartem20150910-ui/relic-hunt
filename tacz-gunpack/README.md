# Relic Hunt: Arsenal — TaCZ Gun Pack

This folder is the start of a **separate, original TaCZ gun pack** for Minecraft 1.21.1 NeoForge, subject to verifying the exact TaCZ port and its gun-pack schema.

Planned guns: revolver, Python, M92, AK, LR-300, MP5, Thompson, Custom SMG, SAR, M39, L96, double barrel, pump shotgun, SPAS-12, M249, rocket launcher, ruby rifle.

Each requires original 3D models, textures, sounds, animations, ammo and tested TaCZ definitions. None of those assets or gun behaviors are implemented yet. Do not redistribute third-party gun assets without permission.

The old CrossbowItem prototypes were intentionally removed from the NeoForge migration branch. Fabric branch remains unchanged.
